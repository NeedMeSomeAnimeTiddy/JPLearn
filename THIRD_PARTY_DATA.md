# Third-Party Data

## Japanese Pitch Accent

JPLearn's optional offline dictionary download includes pitch-accent data from
the [Japanese Language Data](https://github.com/jkindrix/japanese-language-data)
project, derived from the [Kanjium](https://github.com/mifunetoshiro/kanjium)
`accents.txt` dataset by mifunetoshiro and contributors.

The downloaded data is licensed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). JPLearn stores
the data as a separate SQLite table; the application source remains licensed
under Apache-2.0.

Source snapshot:
`jkindrix/japanese-language-data@v0.7.2/data/enrichment/pitch-accent.json`
